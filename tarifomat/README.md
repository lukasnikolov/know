# EPET Tarifomat – profesionální verze

Soubory:

- `index.html` – struktura aplikace, připravená pro GitHub Pages / vložení do Google Sites.
- `style.css` – veškeré vzhledové úpravy; pro změnu barev, karet, typografie či responzivity upravujte tento soubor.
- `app.js` – interakce a **původní matice dokumentů** (převzata z dodaného souboru).

Pro nasazení nahrajte celou složku `tarifomat` do repozitáře s aktivním GitHub Pages. Stránka pak poběží na adrese ve tvaru `https://uzivatel.github.io/repozitar/tarifomat/` a tu lze vložit do Google Sites jako URL.

Samostatný soubor `EPET_Tarifomat_PROFESIONALNI.html` lze otevřít bez dalších souborů a bez internetového připojení.

**Podstatná poznámka:** Pracovní pomůcka přebírá interní matici dokumentů dodanou ve zdrojovém HTML (v něm uvedená verze 04. 11. 2025). Není to kontrola její platnosti ani ověření požadavků ČEZ Distribuce, EG.D nebo PRE. Pro zvolené kombinace, které matice neobsahuje, program zobrazí upozornění. Při změně počtu fází jističe žádá individuální prověření.

Při kliknutí na „Kopírovat dokumenty“ program kopíruje orientační seznam. Neodesílá žádná data do externích služeb.
