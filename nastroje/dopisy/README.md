# Dopisy – Znalostka

Samostatný katalog pro dvě kategorie: **Generátory dopisů** a **Šablony dopisů**.

- Veřejná stránka GitHub Pages: https://lukasnikolov.github.io/know/nastroje/dopisy/
- `index.html` obsahuje rozhraní, styly, filtrování i seznam odkazů.
- Původ dat: HTML „Pravidla pro tisk a šablony“, dodaný 19. 11. 2026. Z původního souboru byly převzaty pouze seznamy `Generátory dopisů` (18 položek) a `ŠABLONY DOPISŮ` (35 položek).
- Další kategorie ze zdrojové aplikace nebyly do katalogu zahrnuty.
- Generátory odkazují na existující stránky Google Sites; šablony na Google Docs/Drive. Obsah externích dokumentů ani jejich oprávnění aplikace nemění.
- Přepínač epet / Dobrá Energie filtruje šablony podle `brand`; odkazy na generátory ve zdrojových datech značku neměly, proto se zobrazují v obou pohledech.
- Aktualizace: upravte pole `DATA` v `index.html` a následně publikujte změnu do `main`.
- Katalog je také dostupný přes tlačítko **Dopisy** v aplikaci [E-mailové šablony](../../sablony/).

**Upozornění:** GitHub Pages je veřejně přístupné. Neumisťujte sem osobní údaje zákazníků, přístupové údaje ani důvěrné informace.
